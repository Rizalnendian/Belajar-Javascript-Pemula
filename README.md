## About the Project 🤔

`Belajar-Javascript-Pemula` is a beginner-friendly repository designed to guide individuals through the fundamentals of JavaScript programming. It breaks down core concepts into manageable HTML and JavaScript files, making it easy to follow along and practice.

---

## Features ✨

- **Environment Setup Guidance:** Learn how to set up your development environment with Chrome and VSCode.
- **JavaScript Execution:** Understand different ways to run JavaScript code (inline, internal, external).
- **Core JavaScript Concepts:** Deep dive into variables (`let`, `var`, `const`), data types (String, Number, Boolean, Null, Undefined, BigInt, Symbol), and their behaviors.
- **String Manipulation:** Explore string escaping, literal templates, and common string operations (charAt, concat, indexOf, substring, slice, replace, toLowerCase, toUpperCase).
- **Clear Examples:** Each concept is illustrated with practical code snippets.

---

## Tech Stack 💻

- **HTML:** For structuring the content and providing a basic web page for JavaScript execution.
- **JavaScript:** The core language for learning and implementing the concepts.

## How to Use 🤔

This repository serves as a practical guide for beginners learning JavaScript. Follow these steps to make the most out of it:

1. **Set up your Environment:**
   - Install Google Chrome (or any modern web browser).
   - Install Visual Studio Code (or your preferred code editor).
   - The `02 - Instalasi Chrome dan VSCode/` folder provides basic guidance on this setup.

2. **Explore Each Lesson:**
   - Each numbered folder corresponds to a specific JavaScript topic.
   - Open the `index.html` file in each folder using your web browser.
   - **Crucially, open your browser's developer console (usually F12) to see the output of `console.log()` statements.** This is where the results of the JavaScript code will be displayed.

3. **Analyze the Code:**
   - Examine the `index.html` files to see how JavaScript is included (inline, internal `<script>` tags, or external `.js` files).
   - Study the corresponding `script.js` files to understand the implementation of each concept.

**Real-world Use Cases Demonstrated:**

While the examples are fundamental, they build the groundwork for:

- **Interactive Web Pages:** Understanding variables and data types is essential for dynamic content.
- **User Input Handling:** Concepts like string manipulation are crucial for processing user input from forms.
- **Data Processing:** Learning how to parse and manipulate data (like converting strings to numbers) is a common task.
