Javascript variabel

let

  • punya Block Scope. Variabel hanya hidup di dalam kurung kurawal {} tempat ia dideklarasikan
  • harus dideklarasikan sebelum digunakan
  • Nilainya bisa dirubah
  • tidak bisa dideklarasi ulang di scope yang sama

var

  • Memiliki sifat function scope. Variabel masih bisa diakses dari luar {}
  • Bisa deklarasi ulang
  • Mengalami hoisting penuh: variabel diinisialisasi dengan nilai undefined sebelum kode dijalankan.

const

  • tidak bisa di deklarasi ulang
  • tidak bisa Reassigned atau nilainya diganti
  • punya Block Scope. Variabel hanya hidup di dalam kurung kurawal {} tempat ia dideklarasikan
